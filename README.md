# pitch-deck-skill

Презентации PowerPoint и PDF в Codex и Claude Code.

Скилл собирает презентации из текста, таблиц, PDF и существующих дек. Сначала подбирает подходящие готовые слайды из всей галереи, затем подставляет новые данные, адаптирует разметку и проверяет результат. Учитывает референс, сверяет числа с источниками и сохраняет редактируемые исходники.

В библиотеке 138 компонентов и 152 примера слайдов, включая схемы, диаграммы, таблицы и текстовые композиции. Галерею можно собрать в двух темах; примеры содержат демонстрационные данные, которые заменяются данными проекта.

## Установка

- [Установить в Codex](docs/install-codex.md)
- [Установить в Claude Code](docs/install-claude-code.md)
- [Скачать установочный файл](https://github.com/aleksandrermolov87-cloud/pitch-deck-skill/releases/latest)

Базовый режим использует встроенную библиотеку. Подключение 21st и генерации изображений настраивается отдельно.

## Как пользоваться

Приложите материалы и опишите результат:

```text
Используй pitch-deck-skill.
Собери коммерческую презентацию на 8 слайдов, белый фон, формат 16:9, PDF.
Сохрани все условия из файла. Один вывод на слайд, оффер в конце.
За основу оформления возьми приложенный референс.
```

Можно создать новую презентацию, переработать существующую или внести точные правки. Для PDF сохраняются исходники; для PowerPoint доступны редактируемые фигуры и диаграммы.
