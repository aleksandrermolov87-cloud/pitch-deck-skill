# pitch-deck-skill

Скилл для Codex и Claude Code: создание и редактирование презентаций PowerPoint и PDF по таблицам, документам, старым слайдам и скриншотам.

Помогает собрать структуру, написать текст, подобрать композиции и схемы, сверить цифры с источниками и проверить готовые слайды. Поддерживает фирменное оформление, работу по референсу и точечные правки существующей презентации. В PPTX текст и данные остаются редактируемыми; PDF можно собирать отдельно.

## Установка

- [В Codex](docs/install-codex.md)
- [В Claude Code](docs/install-claude-code.md)

Инструкции рассчитаны на локальную работу на macOS. В них есть проверка подписи релиза, установка зависимостей и самопроверка. На Linux установка не проверена; Windows не поддерживается.

## Пример запроса

Приложите исходные материалы и напишите:

> Собери презентацию для управляющей компании по этой таблице: 8–10 слайдов, тёмная тема. Покажи результаты, риски и решения, которые нужно принять. Итог в PowerPoint и PDF.

Можно приложить пример оформления, указать аудиторию, цель и нужный формат. Для правки существующего файла опишите, какие слайды и элементы нужно изменить.

## Обновление

При работе скилл проверяет новые релизы не чаще раза в сутки и предлагает обновиться. Установка обновления требует вашего согласия; подпись проверяется по доверенным ключам текущей версии.
