# pitch-deck-skill

Скилл помогает собирать и редактировать презентации в Codex и Claude Code. Вы даёте ему материалы и задачу, а он подбирает готовые слайды, заполняет их вашими данными и приводит оформление в порядок. Результат можно получить в PowerPoint или PDF.

В комплект входят 152 примера слайдов и 138 компонентов: схемы, графики, таблицы и текстовые композиции. Скилл изучает предоставленные референсы, подбирает форму под содержание, проверяет источники и сохраняет редактируемые исходники.

## Как установить

Скилл работает на macOS и Linux. Для установки нужен локальный Codex или Claude Code с доступом к терминалу; Windows напрямую пока не поддерживается. До установки проверьте [необходимые программы](docs/requirements.md). При установке нужен интернет для загрузки скилла и программных зависимостей. Платные ключи и внешние сервисы для базового режима не нужны.

### В Codex

1. Откройте Codex и отправьте ему эту просьбу целиком:

   ```text
   Установи pitch-deck-skill по инструкции:
   https://github.com/aleksandrermolov87-cloud/pitch-deck-skill/blob/main/docs/install-codex.md
   ```

2. После установки откройте новый чат, приложите материалы и попросите: «Используй pitch-deck-skill и собери презентацию по этим материалам».

### В Claude Code

1. Откройте Claude Code и отправьте ему эту просьбу целиком:

   ```text
   Установи pitch-deck-skill по инструкции:
   https://github.com/aleksandrermolov87-cloud/pitch-deck-skill/blob/main/docs/install-claude-code.md
   ```

2. После установки откройте новую сессию, приложите материалы и попросите: «Используй pitch-deck-skill и собери презентацию по этим материалам».

Можно установить скилл и самостоятельно через терминал: команды находятся в инструкциях для [Codex](docs/install-codex.md) и [Claude Code](docs/install-claude-code.md). Если скилл уже установлен, воспользуйтесь [инструкцией обновления](docs/updating.md), а не устанавливайте вторую копию.

## Как пользоваться

Приложите материалы и опишите результат:

```text
Используй pitch-deck-skill.
Собери коммерческую презентацию на 8 слайдов, белый фон, формат 16:9, PDF.
Сохрани все условия из файла. Один вывод на слайд, оффер в конце.
За основу оформления возьми приложенный референс.
```

Можно создать новую презентацию, переработать существующую или внести точные правки. Для PDF сохраняются исходники; для PowerPoint доступны редактируемые фигуры и диаграммы.
