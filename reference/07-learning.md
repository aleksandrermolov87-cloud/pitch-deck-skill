# Этап 7. Обучение: оценки слайдов в пару кликов

Цель: после каждой деки пользователь отмечает, какие слайды получились, а какие нет. Хорошие становятся
эталонами (PNG и код функции слайда), плохие с причиной копятся и превращаются в правила. Следующая дека
на этапах 0, 3 и 6 начинается с чтения `learnings/LESSONS.md`.

## Порядок

1. **Контакт-лист и вопросы:**
   ```bash
   $SKILL/.venv/bin/python -I $SKILL/scripts/learn.py sheet src-<тема>
   ```
   Скрипт пишет `out/review/sheet.png` (все слайды сеткой, у каждого номер и архетип) и печатает JSON с готовыми пачками вопросов.

2. **Покажи слайды:** `SendUserFile` с `sheet.png` (display: render), чтобы пользователь видел все слайды сразу.

3. **Первый клик — общий вопрос** (`AskUserQuestion`, один вопрос):
   - «Все хорошие — в эталоны (Recommended)», если на этапах 4–6 не осталось оговорок;
   - «Отмечу по слайдам»;
   - «Пропустить обучение».

   Если ответ «Все хорошие», все слайды пишутся как good, переходи к шагу 5.

4. **Оценка по слайдам:** вызывай `AskUserQuestion` с пачками из JSON, по 4 вопроса за вызов, multiSelect. В каждом вопросе варианты «Хорошо», «Плохо: композиция», «Плохо: текст», «Плохо: данные», а через «Other» можно написать комментарий. На деку из 12 слайдов уходит 3 экрана кликов.
   - Если выбрано «Хорошо» вместе с «Плохо: …», считай слайд хорошим с замечанием (verdict good, reasons заполнены).
   - Текст из «Other» сохраняется в `comment`.

5. **Запись:**
   ```bash
   $SKILL/.venv/bin/python -I $SKILL/scripts/learn.py record src-<тема> --ratings '{"1":{"verdict":"good"},"4":{"verdict":"bad","reasons":["композиция"],"comment":"пусто справа"}}'
   ```
   - `learnings/ratings.jsonl` получает строку на слайд (дека, архетип, заголовок, вердикт, причины, комментарий);
   - `learnings/gallery/good|bad/` получает PNG, у хороших ещё и `.js` с функцией слайда;
   - `learnings/LESSONS.md` пересобирается: по архетипам эталоны, частые причины, «кандидаты в правила».

6. **Закрепление.** Если в LESSONS.md появился кандидат в правило (одна и та же причина 2+ раза на архетипе):
   - сформулируй правило одной строкой и спроси через `wrap_up` (кнопки «Добавить правило» / «Не надо»), добавить ли его в `reference/05-taste-pass.md`, `04-grid-impeccable.md` или `brands/<бренд>.md`;
   - если вывод касается вкуса пользователя в целом («не люблю пустоты справа»), сохрани его и в память как `feedback`.

7. **Плохие слайды этой деки** не оставляй как есть: предложи переделку прямо в этом ходе (вопрос в `wrap_up` с кнопкой «Переделать слайды N, M»).

## Как уроки используются дальше

- **Этап 0:** в плане есть строка «Уроки», из LESSONS.md берутся эталоны по нужным архетипам и действующие правила.
- **Этап 2:** если для архетипа есть эталон, начинай с его `.js` из `learnings/gallery/good/`, а не с нуля. 21st нужен только для того, чего в эталонах нет.
- **Этап 5:** причины из «Что не нравилось» добавляются в чек-лист этой деки.

## Форматы

`ratings.jsonl`, строка:
```json
{"date":"2026-10-26","deck":"Каналы_и_продукты_2027","slide":3,"fn":"matrix","archetype":"heatmap-matrix",
 "title":"КД и шт. по каналам","verdict":"good","reasons":[],"comment":"","png":"…/gallery/good/….png"}
```
Архетип берётся из поля `archetype`, которое возвращает функция слайда в `slides.js`. Если его нет, используется имя функции. Ставь архетипы из `patterns/slide-archetypes.md`, тогда уроки накапливаются между деками.
