# Codex, Claude Code и ZCode Agent

Один SKILL.md и одна библиотека используются во всех трёх клиентах. `$SKILL` всегда означает папку реально прочитанного SKILL.md; пути автора не нужны.

| Клиент | Новая установка | Вызов |
|---|---|---|
| Codex | ~/.agents/skills/pitch-deck-skill | $pitch-deck-skill |
| Claude Code | ~/.claude/skills/pitch-deck-skill | /pitch-deck-skill |
| ZCode Agent | ~/.zcode/skills/pitch-deck-skill | $pitch-deck-skill |

В ZCode после установки обнови Settings → Skills → Refresh. Уже установленный навык можно импортировать через Import → Symlink, сохранив одну общую копию. Инструкции: [установка](../docs/install-zcode.md), [MCP](../docs/configuration.md#mcp-в-zcode-agent).

Используй доступные инструменты файлов и терминала текущего клиента. Для управления приложениями прочитай встроенный Computer Use; для веб-страниц — Browser Use. Не воспроизводи чужие названия API, request_access или SendUserFile, если таких инструментов нет. Готовые PDF/PPTX передавай как файлы и ссылки в формате текущего клиента.

Codex image_gen не предполагается в ZCode. Генератор выбирается по фактически доступным инструментам; MagicPatterns применяется только после настройки и входа, при отсутствии генератора используются готовые ресурсы и редактируемая векторная графика. Скрипт mcp_setup.sh --check --client zcode проверяет запись конфигурации, не подключённость инструмента, и не меняет настройки других клиентов. Setup и updater с --no-mcp не добавляют серверы.

Библиотека 200 содержит готовые нативные страницы и исходники новых 48 композиций. Сначала просмотри подходящие превью и контракт. Для программной адаптации скопируй source/ и соседний approval.json в проект. Для сборки вне дерева скилла используй NODE_PATH="$SKILL/node_modules" node build.js из скопированной папки source. Тексты и схемы остаются редактируемыми. Styrene устанавливается из собственного лицензированного пакета. После изменения текста или геометрии повтори форматные проверки и нативный экспорт; готовые превью не доказывают качество изменённого слайда.
