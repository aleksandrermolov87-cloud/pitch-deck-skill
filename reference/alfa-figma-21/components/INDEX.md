# Компоненты из двух секций Figma

14 исходных групп для работы с тезисами, доказательствами, инициативами и показателями. Геометрию и базовые кегли сняли со слоёв файла. На превью каждый фрагмент показан вместе с фоном исходного слайда.

[Альбом с деталями](<14 компонентов исходника.pdf>) · [Редактируемые слои Figma](<14 компонентов исходника.fig>) · [Компоненты PowerPoint](<14 компонентов исходника.pptx>) · [Размеры и стили в JSON](components.json)

Координаты отсчитываются от левого верхнего угла исходного слайда 1920 × 1080. Четыре числа обозначают x, y, ширину и высоту в px. В Figma можно копировать весь фрейм либо его внутренние слои. Встроенные изображения остаются растровыми. У ленты направлений в альбоме видна соседняя вводная плашка. В редактируемых файлах сохранена сама лента из четырёх сегментов. Библиотека PowerPoint содержит 77 редактируемых полей. Для исходной типографики на компьютере нужны Montserrat, Styrene A LC, Roboto и Inter.

## Как устроены исходные страницы

| Страницы | Порядок чтения и применение |
| --- | --- |
| 1–3 | В резюме взгляд сначала находит крупные числа, затем горизонтальную ленту направлений. На рыночном слайде размер рынка и вывод занимают разные поля. Для анализа трендов название, короткая расшифровка и предметная иллюстрация собраны в одной группе. |
| 4–5 | Верхняя полоса формулирует предложение, средний ряд раскрывает инициативы, нижняя часть связывает предложение с амбицией. Один 3D-объект отмечает цель или итог. Фоновые цифры помогают удержать место элемента в короткой серии. |
| 6–9 | Содержание определяет оси. План работы выровнен по времени, конкурентное сравнение по общим критериям, пилот по вопросам проверки, финансирование по статьям и итогу. Границы таблицы нужны там, где читатель сопоставляет значения по строкам. |
| 10–14 | Ряд инициатив слева сохраняет постоянное место, текущая инициатива выделена. Справа меняются обоснование, действие и ожидаемый эффект. Такой повтор помогает сравнивать последовательные страницы. |
| 15–18 | Красная обложка открывает отдельный раздел. В аналитике плотность выше. Рыночный фактор, подтверждение и реакция читаются одной строкой, таблица конкурентов использует общие колонки, графики показывают динамику показателей. |
| 19–21 | Строка квартального мониторинга связывает название показателя с весом и парами значений. Итоговая полоса закрывает расчёт. На странице о дисциплине поручений решение сопоставляется с динамикой показателя, в приложении сохранена детализация. |

Для чтения с экрана увеличивай плотные фрагменты до ширины рабочего поля. Например, подписи мини-графика исходно имеют базовый кегль от 7,37 px. На проекторе вынеси главное наблюдение в заголовок и перестрой подписи под дистанцию просмотра. Цвета статусов и сравниваемые периоды переноси вместе с легендой.
