# Как собрать новую презентацию по исходным слайдам

1. Сформулируй вопрос зрителя и тот вывод, который допускает материал. В [каталоге](INDEX.md) найди две близкие страницы, посмотри их рендеры и соседние компоненты из штатной галереи. Сверь количество смысловых групп, наличие данных для диаграммы и роль самого крупного элемента. Для одного наблюдения с реакцией подходит строка страницы 16, для динамики с составом — страница 18.
2. Возьми выбранный слайд из исходного PowerPoint. Сохрани расположение функциональных зон, подложки, используемые начертания, отступы и иерархию. Подпиши каждую зону данными нового брифа. Счётчики, годы, оговорки, легенды и мелкие подписи тоже требуют решения. При повторяющихся инициативах доступны отдельные состояния на страницах 10–14.
3. Посмотри, что запечено в изображениях. Иллюстрацию сохраняй, если она по-прежнему обозначает нужный предмет. Скриншот замени на соответствующий новому продукту. Область с прежними числами или графиком освободи и построй по актуальным данным. Для столбцов и линий доступен штатный компонент `nativeChart` через [адаптер](gallery-chart.cjs). Диаграммы с накоплением поддерживают несколько рядов.
4. При переносе текста сравни новый объём со старым. Сохрани заметное различие между выводом, аргументом и подписью. Когда подпись хуже читается, сначала измени длину формулировки или ширину колонки. Сроки, единицы измерения, названия категорий и ограничения должны пережить такую правку.
5. Сделай рендер PowerPoint. Сопоставь его с [исходным PDF](originals.pdf) при одинаковом масштабе. Проверь, что у заголовка тот же приоритет, подложки по-прежнему объединяют нужные фрагменты, иллюстрация связана с выводом, а значения согласованы с высотой столбцов. В таблице прочитай каждую строку поперёк. Проверь полный монтаж и крупно страницы со сложными наложениями. Пробы остаются в проекте пользователя до его решения о включении.

**Выбор и извлечение.** В командах `SKILL` указывает на установленную папку pitch-deck-skill. Номера соответствуют каталогу. Один оригинал можно использовать несколько раз в произвольном порядке.

```sh
LIB="$SKILL/reference/alfa-figma-21"
PY="$SKILL/.venv/bin/python"
"$PY" -I "$SKILL/scripts/gallery_index.py" --library all --search пилот
"$PY" -I "$LIB/reuse.py" extract 21 report-template.pptx
"$PY" -I "$LIB/reuse.py" extract 4,8,16,18,21 selection.pptx
"$PY" -I "$LIB/reuse.py" inspect 16 > page-fields.json
```

**Подстановка.** У командного файла JSON верхнее поле `slides` содержит упорядоченный список страниц. Для каждой укажи `source` (номер оригинала), `fields` (ID исходного текстового объекта и новый текст или оформленные абзацы), `keep_pictures`, `replace_pictures` и `remove`. Для каждой исходной картинки и каждого текстового поля нужно принять решение. ID и координаты даёт `inspect`. Все координаты относятся к холсту 960 × 540 pt. Идентификаторы объектов берутся из PPTX и отличаются от Figma node-id. При замене изображения соблюдай пропорции исходной области.

Для дополнительных объектов в `add` предусмотрены типы `text`, `panel`, `chart`. У диаграммы указываются область, тип, категории, ряды, цвета и максимум шкалы. Чтобы задействовать штатную галерею, используй поле `gallery` с входными данными `nativeChart` и `styles` с оформлением каждого ряда. Готовая диаграмма содержит встроенную таблицу Excel. Для новых диаграмм с отрицательными значениями или другой шкалой используй подходящий компонент штатной галереи; этот сборщик предназначен для показанных положительных рядов. В заметки страницы вынеси источник и расчёт производных значений. Для ручной работы можно редактировать извлечённые слайды непосредственно в PowerPoint.

```sh
"$PY" -I "$LIB/reuse.py" build brief.json result.pptx
# После экспорта result.pptx в PDF
"$PY" -I "$LIB/check_export.py" result.pptx result.pdf
```

Проверка сопоставляет слова каждого нативного поля с его координатами в PDF. Отдельно осмотри подписи внутри изображений, правильность графиков и баланс страницы. Для точного вида оригиналов используй FIG или PDF. В редактируемом PowerPoint часть исходных эффектов и групп сохранена картинками.
