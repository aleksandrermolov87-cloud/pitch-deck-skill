# Этап 4. Сетка, размеры, отступы, композиция (impeccable)

## Сетка холста 13,333 × 7,5″

| Зона | Значение |
|------|----------|
| поля слева и справа | 0,6″ (`canvas.margin`) |
| шапка | заголовок на y 0,38″, плашка и подзаголовок на y 1,26″ |
| тело | y от 1,92 до 6,82″ (`bodyTop`, `bodyBottom`), внутренний отступ панели 0,45″ |
| подвал | сноска и номер на y 6,94″ |
| шаг | 0,05″. Все x, y, w, h кратны шагу, если их не считает формула |
| колонки | 12 колонок по ширине тела (11,33″ без внутренних отступов), промежуток 0,2″ |

## Шкала размеров

| Роль | pt |
|------|----|
| число-герой (главный KPI) | 60–80 |
| заголовок слайда | 28–36 (уменьшается под длину, минимум 24) |
| подзаголовок | 15 |
| заголовок блока | 14–18 |
| текст карточки | 11–12 |
| подпись, легенда | 9,5–10 |
| сноска | 9 |
| абсолютный минимум | 8 (кроме подписей осей при 12+ столбцах — 7,5, с записью в отчёт) |

На слайде не больше 8 разных кеглей: шапка забирает 5, телу остаётся 2–3.

## Отступы

- Внутри карточки 0,14–0,2″, между карточками 0,2–0,25″, между блоками тела 0,35–0,5″.
- Подпись к элементу ближе к нему, чем к соседнему элементу (закон близости).
- Межстрочный интервал: 1,1–1,15 для многострочного текста, 1,0 для однострочных подписей в фиксированных боксах.

## Композиция: чек-лист глазами по PNG

- [ ] У слайда **один фокус**: самое крупное и контрастное — это вывод из заголовка.
- [ ] Нет пустоты больше ~25% тела без функции. Лечение: растянуть сетку на высоту тела, укрупнить данные, добавить фоновую графику в стиле бренда или визуал справа. Мелкий текст в углу не лечит пустоту.
- [ ] Нет слипаний: между текстом и линией не меньше 0,08″, подписи на связях схемы не касаются линий и узлов.
- [ ] Схемы: связи не пересекают узлы, основные связи сплошные, дополнительные пунктиром и тоньше, у узлов одинаковый размер, если нет причины.
- [ ] Ряды карточек одной высоты, верхние края на одной линии, тексты начинаются на одной базовой линии.
- [ ] Левые края текстов совпадают с линиями сетки. «Почти совпадающие» края (разница меньше 0,05″) ловит `pptx_audit.py`.
- [ ] Ритм: соседние слайды не повторяют один и тот же макет три раза подряд.
- [ ] Числа в колонках выровнены вправо или по запятой, табличные цифры (`tabular-nums`).

## impeccable

Если impeccable установлен со своими хуками, они срабатывают на правки HTML-двойника (это настройка impeccable, скилл её не меняет). Вручную:

```bash
zsh $SKILL/scripts/impeccable.sh detect src-<тема>/out/deck.html          # человекочитаемо
zsh $SKILL/scripts/impeccable.sh detect --json src-<тема>/out/deck.html   # для разбора
zsh $SKILL/scripts/impeccable.sh context                                  # контекст проекта
zsh $SKILL/scripts/impeccable.sh --where                                  # где установлен impeccable
```

Правила качества impeccable лежат в его папке: `reference/craft-floor.md` и `polish.md` (папку показывает `impeccable.sh --where`). Перед этапом 4 прочитай `craft-floor.md`.

Исключение ставь только с причиной и только для файла деки:
```bash
impeccable hooks ignore-value tight-leading "*" --file "src-<тема>/out/deck.html" \
  --reason "Claude: line-height 1.2 только у однострочных подписей в фиксированных боксах PPTX"
```
Уже записанные исключения лежат в `.impeccable/config.json` проекта.

## pptx_audit.py

```bash
$SKILL/.venv/bin/python -I $SKILL/scripts/pptx_audit.py <файл.pptx> [--theme src-<тема>/theme.json] [--strict]
```
ERR (код выхода 1): вылет за холст, кегль меньше минимума, шрифт не из темы.
WARN: заход в поле, больше 8 кеглей, больше двух насыщенных оттенков, почти совпадающие края, пересечение текстов, пустая нижняя треть или правая часть тела, тире вместо маркера, больше одной средней точки в строке, декоративная нумерация 01/02, «Шаг 1», слова-штампы, двойные пробелы, одинаковые заголовки на разных слайдах.

Каждое WARN либо исправь, либо объясни в отчёте («пустота справа под 3D-объект, который вставит пользователь»).
