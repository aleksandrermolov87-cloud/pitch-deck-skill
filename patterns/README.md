# База паттернов питч-деков

Как пользоваться: определи **аудиторию и решение**, выбери паттерн по таблице, возьми из него порядок
слайдов и плотность, затем подбери архетип для каждого слайда в `slide-archetypes.md`. Заголовки
пиши по `narrative.md`.

## Выбор паттерна

| Аудитория | Какое решение нужно | Паттерн | Слайдов | Плотность |
|-----------|---------------------|---------|---------|-----------|
| ангел, pre-seed / seed фонд | встреча → чек | `investor.md` → Seed | 10–12 | низкая, показ вживую |
| фонд серии A | вход в раунд | `investor.md` → Series A | 12–15 + приложение | средняя, метрики |
| фонд роста, стратег | крупный раунд, M&A | `investor.md` → Growth | 15–20 + приложение | высокая |
| рассылка инвесторам до встречи | ответить на письмо | `investor.md` → Send-ahead | 10–14 | читается без голоса |
| УК, правление, комитет | утвердить, выделить ресурс, принять статус | `corporate.md` → Решение / Бюджет | 5–10 | средняя, вывод первым |
| руководитель блока, квартальная встреча | принять результат, согласовать план | `corporate.md` → Отчёт план/факт | 6–12 | средняя |
| внутренний «стартап» в корпорации | запустить пилот | `corporate.md` → Интрапренёр | 8–12 | низкая |
| корпоративный клиент B2B | пилот, договор | `b2b.md` → Продажа | 8–12 | низкая |
| партнёр, канал дистрибуции | партнёрство | `b2b.md` → Партнёр | 8–10 | средняя |
| команда, смежники | синхронизация | `product.md` → Роадмап / Запуск | 5–10 | высокая допустима |
| еженедельный статус | увидеть риски | `corporate.md` → Статус | 1–3 | карточки 1–4 на слайд |

## Общие правила для всех паттернов

1. **Вывод первым.** У инвестора это проблема и решение, у УК ответ и просьба, у клиента его выгода. История, методология и детали идут ниже или в приложение.
2. **Одна мысль на слайд**, заголовок-вывод (см. `narrative.md`).
3. **Просьба явная:** сумма, ресурс, решение, срок. Без последнего слайда «Спасибо за внимание».
4. **Цифры с источником и периодом.** У инвестора прогноз отделён от факта.
5. **Приложение** для глубины: финмодель, методика, полные таблицы. Основная часть не перегружается «на всякий случай».
6. **Показ вживую и рассылка — разные деки.** На показе меньше текста и крупнее, у рассылки текст несёт смысл без докладчика. Если нужна одна дека, сделай заметки докладчика (`notes`).
