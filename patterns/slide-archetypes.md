# Каталог архетипов слайдов

Идентификатор архетипа (в скобках) ставится в поле `archetype` функции слайда. По нему копятся оценки
(этап 7) и находятся эталоны в `learnings/gallery/good/`. Запросы для 21st — в `reference/02-components-magic.md`.

## Открытие и структура

**Обложка (`cover`).** Вывод деки одной фразой, акцентное слово, подзаголовок «для кого / когда», знак бренда, контекстный 3D-объект (`hero`) про суть деки. Без даты-«эйбрау» и без логотипов партнёров.

**Раздел (`section`).** Крупное название раздела и одна строка «что в нём». Нужен только если в деке 15+ слайдов.

**Главное (`summary`).** 3–5 выводов деки, у каждого число. Обычно идёт вторым слайдом для УК.

## Числа

**Число-герой (`kpi-hero`).** Одно крупное число (60–80 pt) слева с подписью и инфографикой состава или тренда под ним (мини-столбики, спарклайн), справа 2–4 вторичных числа строками с разделителями. Не три одинаковые карточки. Заголовок не повторяет число-героя.

**План / факт (`plan-fact`).** Серые столбики плана, акцентные столбики факта, отклонение подписано (+12%). Легенда в одну строку справа от подзаголовка.

**Тренд (`bars-trend`).** Столбики по периодам, последний акцентом, значения над столбиками, скобка роста «xN» от первого к последнему. Ось без сетки.

**Структура (`stacked-share`).** Полосы долей по категориям (каналы, продукты), цвет по группам, подписи долей внутри полос, итог справа. Вместо круговой диаграммы с 5+ секторами.

**Матрица (`heatmap-matrix`).** Строки × столбцы (продукты × каналы), насыщенность акцента по величине, в ячейке 1–2 числа. Итоги строк и столбцов вынесены за сетку.

**Воронка (`funnel`).** 4–6 этапов, ширина пропорциональна величине, конверсия между этапами подписана.

**Рынок (`market-tam`).** TAM/SAM/SOM вложенными кругами или ступенями, у каждого расчёт снизу вверх в сноске.

## Время

**Роадмап по месяцам (`timeline-months`).** Кварталы-пилюли, тоновые полосы через квартал, ось со стрелкой, точки релизов, карточки эпиков от месяца релиза до следующего, под ними столбики денег.

**Роадмап по кварталам (`roadmap-quarters`).** Строки-направления по годам, отметки кварталов квадратами, связанными линией, цвет по годам, пунктир «без срока», разделители лет.

**Гант (`gantt-lanes`).** Дорожки «канал × продукт», фазы разными тонами, итог справа.

**Вехи (`milestones`).** 4–7 вех на одной оси, у каждой дата и результат. Для сроков проекта.

## Связи и процессы

**Схема ролей (`hub-diagram`).** 3–5 узлов с буллетами ответственности, связи основные и дополнительные, подписи на связях. Центральный узел выделен, если он «главное окно».

**Процесс (`process-steps`).** 3–5 шагов слева направо, у каждого шага свой контекстный 3D-объект (`row`, 1,6–2,0″), стрелки между ними, шаг назван по сути, под ним 1–2 строки пояснения. Образец — слайд 4 заготовки.

**Архитектура (`systems-map`).** Системы слоями (каналы → оркестрация → мастер-система → внешние), новое акцентом, старое серым.

**До / после (`before-after`).** Две колонки одинаковой структуры, разница числом между ними.

## Продукт

**Экран продукта (`screenshot-demo`).** Тезисы слева (3–4), справа настоящий экран в высоком разрешении, плашка с ключевым ограничением.

**Карточка продукта (`product-card`).** KPI-стек слева, 5 строк описания справа, **обязательно** 3D-объект продукта (`card`, по брифу из строк карточки), иначе аудит даст «бедный слайд».

**Линейка (`product-lineup`).** Группы продуктов с планом денег и долей, строки продуктов с чеком, КВ, доходом с полиса, каналами.

**Статус (`status-cards`).** 1–4 карточки продуктов со статусом, «Сделано / Планируем», блок «Главное за неделю».

## Люди и доверие

**Команда (`team`).** 3–6 человек: фото, роль, одно доказательство («запустил X в Y»). Без списка вузов.

**Кейс (`case`).** Клиент, задача, решение, результат числом, цитата до 3 строк.

**Конкуренты (`competition-2x2`).** Две оси, важные покупателю, позиции игроков, мы в выгодном углу по реальным данным. Таблица с галочками только если оси не выбрать.

## Просьба

**Просьба (`ask`).** Сумма или решение крупно, 3–4 направления использования полосой долей, веха, срок. Для УК: «прошу утвердить» и варианты A/B с рекомендацией.

**Риски (`risks`).** 3–4 риска: вероятность и влияние (тоном), мера, владелец.

**Следующие шаги (`next-steps`).** 3 шага с датами и ответственными.

## Приложение

**Таблица (`appendix-table`).** Полная таблица мелким кеглем (не меньше 8 pt), источник, дата выгрузки. Только в приложении.
