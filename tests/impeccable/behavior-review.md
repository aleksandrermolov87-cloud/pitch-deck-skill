## Codex-only Impeccable и молчащий SVG scan

Реальный `zsh scripts/impeccable.sh --where` теперь возвращает `~/.codex/skills/impeccable` — маршрут Codex обнаруживается. Изолированный Codex-only fixture в этом агентском прогоне не запускался.

Далее: читать найденный SKILL.md; context один раз в корне проекта; для аудита применимые critique/layout, перед правками craft-floor, перед выдачей polish. Это работа по инструкциям, не выдуманные CLI-команды. Записать замечание → страница/элемент → причина → исправление → проверенный рендер. SVG detector без вывода подтверждает только отсутствие сигналов этого сканера; не подтверждает семантику связей, внешний вид PDF или отсутствие наложений. При hook повторный detect не нужен. Реальный PDF проверяется отдельно по тексту, страницам, шрифтам, геометрии и просмотру монтажа/сложных страниц. Применимые правила: иерархия, масштаб, группировка, контраст, фон и ритм. Hover, motion и responsive-брейкпойнты статическому PDF не приписываются.

## Оставшиеся противоречия на момент проверки

1. SKILL.md, таблица этапов, строка 86: «0 замечаний детектора» против новых ворот 4, где требуется дизайн-проход и границы применимости.
2. SKILL.md, главное п.3 и этап2 п.9: обязательная инфографика/3D/экран и закрытие «бедного» слайда объектом конфликтуют с честной формой D. Исключение только для библиотечных текстовых раскладок недостаточно для обоснованной адаптации.
3. Глобальное «4+ контейнера — ошибка» не различает декоративные карточки и пять связанных смысловых узлов процесса B. Пользовательский запрет плиток следует сохранить, а смысловые узлы со связями разрешить по контракту.
4. reference04 оставляет универсальное требование одинакового размера узлов. В строке есть оговорка «если нет причины», поэтому прямого противоречия нет; причина должна отражать семантику, не удобство заполнения.
5. reference23 требует проверенный рендер как поле контракта «до рендера». До сборки там возможен только критерий проверки; результат и исправление следует дозаполнить после просмотра.

## Итог после финального ревью
Перечисленные конфликты в инструкциях устранены. Shell fixture воспроизвёл RED на Codex-only discovery и прошёл после исправления под bash и zsh на macOS. Проверены четыре корня, пробелы в аргументах, передача ненулевого exit status и отказ от исполняемых файлов текущего проекта. Linux локально не запускался; тест включается существующей CI-петлёй tests/*/run.sh.
