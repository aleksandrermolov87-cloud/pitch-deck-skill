# Журнал изменений

## 1.6.0 — 27.10.2026
- **Приоритет библиотеки компонентов обязателен.** Порядок источников: библиотека → 21st → сборка агентом. 21st больше не запрашивается для каждого слайда с данными, только для слайдов, которым в библиотеке ничего не подошло. Такой слайд возвращает `custom: '<почему>'`.
- Компоненты помечают свои элементы, а `build.js` пишет в `out/slides.json`, какой компонент собрал слайд. Новая проверка `scripts/library_check.py`: ошибка — слайд без компонента и без причины, предупреждение — своя раскладка при наличии компонента того же архетипа. Проверка входит в ворота этапов 2 и 3 и в `setup.sh --selftest`.
- Заготовка `deck-starter/slides.js` переписана на компоненты библиотеки (`kpiHero` + `kpiList`, `barsTrend`, `timelineAxis`, `tableEditorial`, `processSteps`): новая дека начинается с образца «библиотека первой», а не с ручной раскладки.
- **Быстрая правка формулировок через вопросы в чате** (`reference/13-quick-copy-edit.md`). `scripts/copy_edit.py list` показывает тексты слайда и где каждый живёт (поле JSON или строка `slides.js`; поля-источники фактов не правятся). Агент даёт по 3 варианта на текст в одном `AskUserQuestion`. `copy_edit.py apply` применяет выбранное разом: не пропускает новые числа и неоднозначные замены, уточняется путём `where`.
- `render.sh` с `SLIDE='4 7'` рендерит только нужные слайды (около 2 секунд на слайд). Быстрая правка показывает PNG «было → стало» без полной пересборки.
- Правки пишутся в `learnings/copy_edits.jsonl` (локально, не в репозиторий). `learn.py digest` добавляет в `LESSONS.md` раздел «Как пользователь правит формулировки»: последние замены и слова, которые пользователь убирает чаще всего.
- Этап 7: у слайдов с «Плохо: текст» сразу предлагается быстрая правка.
- **Быстрая правка подложки через чат** (раздел «Подложка» в `reference/13-quick-copy-edit.md`). `scripts/bg_edit.py show` показывает параметры фона слайда, `apply --do <приёмы>` меняет их: полосы тише или ярче, без полос, свечение убрать, ослабить или перенести, зерно, «как у слайда M». Если подложку делят другие слайды, скрипт делает копию `bg_n<N>.jpg` (`deck.json → bg_override`), остальные слайды не меняются. Пересобираются только эта подложка и слайд, «было → стало» кладётся в `out/review/`, около 3 секунд на слайд.
- `bg.py` читает параметры подложек из `theme.json → bg.slides` (свечение, сила полос, зерно) и умеет `--only`. Свечения больше не зашиты в код. `build.js` применяет `bg_override` и пишет подложку слайда в `out/slides.json`. Правки подложек идут в `learnings/bg_edits.jsonl`, `learn.py digest` собирает раздел «Как пользователь правит подложки».
- **Приоритет небанальных и передовых референсов** (`reference/14-reference-quality.md`). Рубрика 0–3: небанальность, передовость, совместимость с брендом, честность данных; ворота «бренд ≥ 2, честность ≥ 2». Списки сигналов банальности и передовости, источники передового по задачам деки, лестница замен компонентов библиотеки от банального к сильному.
- Оценщик референсов ставит баллы, направление задаёт самый небанальный референс среди прошедших ворота, банальные дают только токены. В вопросе «Откуда взять стиль?» новый рекомендуемый вариант «Профиль бренда + передовые референсы»: агент сам подбирает 3–5 образцов. Кандидаты 21st сравниваются по той же рубрике, а слайд с 2+ сигналами банальности на этапе 5 возвращается на замену по лестнице.

## 1.5.0 — 27.10.2026
- **Напоминание об обновлении раз в неделю:** `scripts/check_update.sh` проверяет релизы на GitHub не чаще, чем раз в `update_check_days` дней (по умолчанию 7), и сообщает только о релизе, подписанном ключом автора. В начале работы скилл пересказывает, что нового, и предлагает «Обновить сейчас» или «Позже»; сам ничего не ставит. Без сети проверка повторится через день и работе не мешает. Для установки из md предлагает переустановку из git.
- Исправлено: в zsh параметр `--proto =https` без кавычек ломал `curl` — скачивание шрифта по ссылке и демо-3D при чистой установке не работало.
- Исправлено: `update.sh` показывал заголовок CHANGELOG вместо раздела новой версии.
- **Установка без технических знаний:** README и установочные md начинаются с трёх простых шагов («откройте Claude Code или Codex → дайте ссылку или файл → отвечайте на вопросы»); для ассистента — правила общения простыми словами, действия руками по кликам, что делать в чате без доступа к компьютеру и в Codex (ссылка в `~/.codex/skills`). Сроки установки исправлены на 10–15 минут, impeccable и 3D — только по просьбе пользователя.
- `setup.sh --selftest` показывает итог галереи для обеих тем; `doctor.sh` пишет «есть в списке MCP», а не «подключён».

## 1.4.0 — 27.10.2026
Первый публичный релиз на GitHub, по итогам аудита безопасности.
- **Установка и обновление из git:** `git clone` релиза-тега, `scripts/update.sh` показывает изменения в скриптах и инструкциях агента и переключает на новый релиз только с `--yes`; `scripts/release.sh` выпускает версию (проверки, тег, релиз с установочными md и SHA-256).
- **Агентская безопасность:** раздел «Безопасность» в SKILL.md — внешний контент как данные, без команд и ссылок из вводных, скачивание только с CDN Magic Patterns, во внешние сервисы только обобщённое, необратимое только с подтверждения; из шага Figma убраны JavaScript на странице и доступ к Finder.
- **Скрипты:** значения в `node -e` передаются только через аргументы (`scripts/jget.sh`), проверка имён папок, режима, групп галереи и вердиктов оценок; impeccable не ищется в папке проекта; картинки слайдов только из `img/`; Chrome с песочницей, временный профиль через `mktemp`, CSP в HTML-двойнике, экранирование атрибутов.
- **Шрифт:** только https, необязательный `FONT_SHA256`, распаковка только .otf/.ttf без путей и ссылок.
- **Цепочка поставок:** `requirements.txt` с версиями (+ defusedxml), `package.json` и `package-lock.json`, `npm ci --ignore-scripts`; демо-3D только с `https://cdn.magicpatterns.com/`, с ограничением размера и сверкой sha256, если он указан.
- **Утечки:** `scripts/leakcheck.sh` (ключи, токены, личные пути + локальный список `scripts/leaks.local.txt`), pre-commit-хук, CI на GitHub Actions; `.gitignore` для всего локального.
- **Установка из md:** распаковка во временную папку с проверкой записей архива, хэш сверяется с релизом на GitHub.
- Примеры и демо-данные обезличены: вымышленные числа и названия каналов.
- README, LICENSE (MIT), THIRD_PARTY.md, SECURITY.md, CODEOWNERS.
