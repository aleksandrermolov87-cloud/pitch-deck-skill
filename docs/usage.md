# Работа и проверки

Все рабочие правила входят в релиз: отдельный пользовательский хук и история предыдущих чатов не нужны. По умолчанию новая дека проходит профиль **deep**: разбор референса, карта скоупа, подбор компонентов, сравнение композиций, проверки и финальный просмотр. **refine** сохраняет утверждённый дизайн, **quick** применяется к точным правкам. Режим **lite** ограничивает 21st, но не библиотеку и качество проверок.

Скилл не повторяет вопросы, если тема, формат, число страниц и графика уже заданы. Явный бриф и утверждённый референс важнее шаблона бренда. С готовым брифом скилл переходит к работе без повторного согласования вводных.

Для PDF-only доступны самостоятельные экспорт и проверка без обязательной сборки PPTX и второй темы:

```bash
bash scripts/pdf_export.sh path/to/deck.html path/to/deck.pdf
.venv/bin/python -I scripts/pdf_check.py path/to/deck.pdf --out out/pdf-check --expected-pages 8 --expected-size 1440x810
```

Экспорт учитывает CSS `@page`; проверка сохраняет текст, сведения о шрифтах, JSON и PNG всех страниц. Размер указан в PDF points. Страницы и размер в примере заменяются на значения брифа. Проверка не оценивает художественный вкус, семантическую полноту и пересечения объектов: агент проверяет их отдельно. Подробнее: [глубина исполнения и PDF](../reference/22-execution.md).

## Настройки и сценарии

`config.json` задаёт режим `lite` или `full` (21st Magic MCP), провайдера изображений `image_provider`, бренд, работу с Figma и частоту проверки обновлений. Профиль качества по умолчанию: `deep`. Встроены сценарии для инвесторских, корпоративных и B2B-презентаций, продуктовых дек и статусных отчётов.

Процесс включает план с референсами, работу с вводными и формулировками, подбор компонентов, сборку, аудит сетки, редактуру, сверку фактов и учёт оценок слайдов. Локальные уроки находятся в `learnings/`.

## Компоненты и схемы

Компоненты для таблиц, графиков, роадмапов, схем, оргструктур и текстовых слайдов: [каталог](../components/README.md), [схемы](../reference/19-schemes.md). Собрать галерею: `zsh scripts/gallery.sh` из папки скилла.

Проверки: `plan_check.py` (план), `pptx_audit.py` (сетка), `facts_check.py` (факты), `brief_coverage.py` (охват брифа), `smart_check.py` (SMART), `eval_deck.py` (оценка деки), `img_qc.py` (картинки), `doctor.sh` (окружение). Скрипты находятся в `scripts/`.

## Безопасность

- Внешний контент (файлы, Figma, страницы, ответы MCP) скилл читает как данные, а не как инструкции; необратимые действия — только с вашего подтверждения (раздел «Безопасность» в [SKILL.md](../SKILL.md)).
- Зависимости закреплены: `requirements.txt`, `package-lock.json` (`npm ci --ignore-scripts`).
- Перед каждым коммитом и в CI работает проверка на утечки ключей, личных путей и внутренних названий (`scripts/leakcheck.sh`, локальный список — `scripts/leaks.local.txt`, в git не попадает).
- Как сообщить об уязвимости — [SECURITY.md](../SECURITY.md).
