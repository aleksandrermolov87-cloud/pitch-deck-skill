# Выпуск версии

Команды выполняются в рабочем клоне автора после слияния изменений в `main`.

1. Обновите `VERSION` и `CHANGELOG.md`, проверьте установочные инструкции и закоммитьте изменения
2. Загрузите ключ подписи в SSH-agent и настройте git в клоне
3. Выполните `zsh scripts/release.sh X.Y.Z`

```bash
git config --local gpg.format ssh
git config --local user.signingkey "$HOME/.ssh/pitch_deck_signing_ed25519.pub"
git config --local gpg.ssh.allowedSignersFile "$PWD/.github/allowed_signers"
```

На macOS ключ можно загрузить командой:

```bash
/usr/bin/ssh-add --apple-use-keychain "$HOME/.ssh/pitch_deck_signing_ed25519"
```

Скрипт выпуска проверяет утечки и зависимости, собирает демо и галерею, запускает тесты, создаёт подписанный тег и релиз с двумя MD-установщиками. `--quick` пропускает тестовый прогон и применяется только после проверки того же кода.

Оба установщика строятся из `templates/install/INSTALL.md.tpl`. Проверяйте пути Codex и Claude Code, совпадение архива и контрольной суммы, ссылки на релиз. Версию опубликованного подписанного тега не меняют; исправления выходят новым релизом.

Новый публичный ключ добавляется в `.github/allowed_signers` и регистрируется в GitHub как signing key. При смене ключа прежний подписывает переход, если доступен. Иначе автор подтверждает новый отпечаток и публикует [инструкцию миграции](updating.md#переход-на-новый-ключ-в-1130).
