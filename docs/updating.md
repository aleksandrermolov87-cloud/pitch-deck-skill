# Обновление

Укажите текущую папку скилла. Для Codex это обычно `~/.agents/skills/pitch-deck-skill`, в прежних установках также `~/.codex/skills/pitch-deck-skill`. Для Claude Code — `~/.claude/skills/pitch-deck-skill`. В примерах ниже используется путь Claude Code; замените его на свой.


Каждый день в начале работы скилл проверяет, вышел ли новый подписанный релиз, и предлагает обновиться: «Обновить сейчас» или «Позже». Проверка идёт не чаще раза в сутки и только когда скилл запущен; без вашего согласия ничего не ставится. Частота — `config.json → "update_check_days"` (по умолчанию 1, `7` — раз в неделю, `0` — не проверять). Проверить вручную: `zsh ~/.claude/skills/pitch-deck-skill/scripts/check_update.sh --force`.

Обновить вручную:

```bash
zsh ~/.claude/skills/pitch-deck-skill/scripts/update.sh          # покажет изменения
zsh ~/.claude/skills/pitch-deck-skill/scripts/update.sh --yes    # переключит на последний релиз
```

Обновление ставит только релизы (теги `vX.Y.Z`), подписанные ключом автора, и перед этим показывает, что меняется в скриптах и инструкциях агента. Подпись проверяется по `.github/allowed_signers` из уже установленной версии; релиз без подписи или с чужой подписью не ставится. На GitHub у подписанных тегов стоит отметка «Verified». Ваши `config.json`, уроки (`learnings/`) и `*.local.md` не входят в git и не меняются.

**Установка без git** (из архива, установщиком скиллов, из md-файла): те же команды. Нужен только git на компьютере, папке скилла `.git` не нужен. `update.sh` скачивает релиз во временный клон, проверяет подпись ключом из текущей установки и показывает CHANGELOG и список изменений. Новая версия собирается в промежуточной папке: туда побайтно переносятся ваши `config.json`, `learnings/`, `*.local.md`, окружение (`.venv`, `node_modules`) и всё, чего нет в релизе. Там же проходят `setup.sh` и быстрая проверка. Только после этого папки меняются местами; если что-то не прошло, установка остаётся как была. Прежняя версия хранится целиком в `~/.claude/skills/.pitch-deck-skill.backups/<время>-v<версия>`. Claude эту папку не загружает, другие скиллы обновление не трогает. Старые копии удаляйте сами, когда новая версия проверена.

```bash
zsh ~/.claude/skills/pitch-deck-skill/scripts/update.sh --rollback        # покажет, какая копия вернётся
zsh ~/.claude/skills/pitch-deck-skill/scripts/update.sh --rollback --yes  # вернёт последнюю резервную копию
```

При откате текущие настройки и уроки переносятся в возвращённую версию, а сама текущая версия становится резервной копией: повторный `--rollback --yes` вернёт её. Тесты обновления работают без сети: `zsh tests/update/run.sh`. Переменная `PDS_REMOTE` подменяет источник релизов в тестах и при однократном переходе из заранее проверенной локальной копии.

## Переход на новый ключ в 1.13.0

Если установка доверяет прежнему ключу, сначала выполните [однократную миграцию](signing-key-migration.md). Затем обычный `update.sh --yes` получит актуальный релиз.
